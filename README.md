# nextendo-dauth (nx-mod testing)

nx-mod's `testing` fork of [nx-dauth](https://github.com/NextendoNetwork/nx-dauth): Device/application authentication server for Nextendo (self-signed Switch dauth chain).
Part of [nextendo-testing](https://github.com/nx-mod/nextendo-testing): the whole Nextendo Network, run on a LAN. Upstream's README is kept as [README.upstream.md](README.upstream.md).

## nx-mod changes

- **dragons `rights/available_elicenses`** (and `elicenses/report`/`extend`): online games stopped at this licence check without it.
- Monster Hunter Generations Ultimate version gate (from CollectingW).
